Author Switch Detector

Analyse writing style across sentences and detect when the author may have changed. Paste any text to inspect it, or train a classifier on a labelled dataset.

Every document analyzed here is expected to already contain an author switch, so deciding whether a document is multi-author is redundant. The two questions that matter are:

Task 1

Where do authors switch?

Find the exact sentence boundaries where the writing style changes from one author to another.

Task 2

Group sentences by author

Cluster the resulting segments by writing style so repeated authors are recognised as the same author, and estimate how many authors wrote the document.

How it works
  1. Inspect: paste or upload text to explore its style
  2. Explore: view statistics over a labelled dataset
  3. Train: fit a classifier on sentence-pair features
  4. Predict: detect author switches in new text
  5. Retrieve: see which sentences of a text are written alike (retrieval model)
  6. Ablation: read the ablation study that supports the features and models
Using the application
  1. Please make sure each sentence starts on its own new line, since this is how the tool tells sentences apart.
  2. We support pasted text as well as uploaded .txt files (PDF support is on the way).
